📊 Análise de Demanda e Forecast

Projeto completo desenvolvido no Power BI com foco em análise exploratória, sazonalidade, performance operacional e previsão de demanda utilizando o dataset Store Item Demand Forecasting (Kaggle).

🔗 Visualizar Dashboard Online

Objetivos do Projeto

  • Identificar padrões de demanda
  • Determinar o padrão de sazonalidade ao longo do tempo
  • Aplicar análise Pareto e classificação ABCs
  • Construir previsão futura de demanda
  • Gerar insights estratégicos para tomada de decisão

1. Overview Executivo

Principais Insights

  • Demanda total apresenta um crescimento consistente ano a ano
  • Store 2 é a top 1 de vendas no período analisado
  • Concentração de demanda ocorre entre Maio e Agosto de cada ano

2. Sazonalidade

Principais Insights

  • Padrão sazonal consistente entre os anos
  • Queda de demanda em Janeiro/Fevereiro e Dezembro
  • Julho é o mês de pico para a categoria

3. Performance

Principais Insights

  • Distribuição da venda bastante heterogênea tanto por item quanto por loja
  • Não concentração de venda por loja ou item representa um equilíbrio do negócio

4. Forecast de Demanda

Principais Insights

  • Crescimento previsto de 3,6% (2018 x 2017)
  • Demanda futura apresenta estabilidade
  • Baixa volatilidade prevista
  • Tendência de crescimento moderado

💰 Dashboard de Finanças Pessoais

Projeto desenvolvido em Power BI com foco em controle financeiro pessoal, O dashboard conta com filtros dinâmicos por ano, mês, categoria, conta, tipo de gasto e status de pagamento, além de comparativo inteligente entre período atual e anterior.

🎯 Objetivos do Projeto

  • Criar um dashboard interativo para acompanhamento das despesas pessoais;
  • Monitorar gastos por período, categoria, conta, tipo de gasto e status de pagamento;
  • Comparar período atual versus período anterior com análise dinâmica mensal e anual;
  • Identificar maiores grupos de despesas e oportunidades de controle financeiro;
  • Disponibilizar uma base reutilizável para acompanhamento financeiro pessoal.
